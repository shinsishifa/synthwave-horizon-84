# 🏎️ Synthwave Horizon '84 — Pseudo-3D Arcade Racer

**Synthwave Horizon '84** is an 80s arcade-style retro pseudo-3D racer built natively for the web. Featuring horizon-projection perspective rendering, accelerating gameplay speed, dynamic traffic obstacles, and retro synthwave aesthetics, it runs smoothly on any modern browser with **zero dependencies**.

---

## 🌟 Key Features

* **Zero External Dependencies:** Built completely with modern HTML5 Canvas, CSS3, and Vanilla JavaScript.
* **Pseudo-3D Projection Engine:** Simulates 3D horizon scaling and road grid movement without heavy 3D frameworks.
* **80s Synthwave Visuals:** Features neon gridlines, sunset radial backdrop gradients, glowing vector cars, and ambient glow effects.
* **Cross-Platform Controls:** Smooth steer binding for keyboard controls (`Arrow Keys` / `A` & `D`) and touchscreen zones.

---

## 🎮 How to Play

1. **Drive:** Click **Drive** to start cruising down the highway.
2. **Steer:** Use **A/D** or **Left/Right Arrow Keys** (or tap left/right on touchscreens) to weave through traffic.
3. **Score:** Earn points for every traffic obstacle you pass while maintaining high speeds!

---

## 🚀 GitHub Pages Deployment Instructions

1. Push `index.html` to the root directory of your GitHub repository.
2. Open your repository on GitHub and navigate to **Settings** $\rightarrow$ **Pages**.
3. Under **Build and deployment**, set the source branch to `main` and directory to `/ (root)`.
4. Click **Save** to receive your live game link (`https://<username>.github.io/<repo-name>/`).
